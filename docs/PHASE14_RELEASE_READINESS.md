## Launch requirements — no deployment performed

1. **Backend:** Python 3.11, dependencies from `backend/requirements.txt`, checked-out `data/` including the demo and catalog, and a long-running ASGI process. Typical hosting command: `python -m uvicorn backend.main:app --host 0.0.0.0 --port <assigned-port>`. Configure the actual port at deployment. Health endpoint: `/api/health`. Treat files as read-only; no database is necessary for the deterministic demo.
2. **Frontend:** install locked dependencies with `npm ci`, run `npm run build`, and host `frontend/dist` as static assets over HTTPS. Build with `VITE_API_BASE_URL=https://<backend-origin>`; never put API keys in Vite variables. Production browser traffic must not point at localhost. Configure a single exact `FRONTEND_ORIGIN=https://<frontend-origin>` on the backend.
3. **Environment:** for the public offline demo set `ORQUESTRA_AI_ENABLED=false`, `AI_MAX_REQUESTS_PER_PROVIDER=0`, and `ORQUESTRA_MDC_DEMO_ENABLED=true` if showing the Cybersecurity overlay. Set `ORQUESTRA_DATA_DIR` only if data is stored outside the default repository location. Hosting must inject environment variables; `backend.main:app` does not automatically load local `.env`. Do not deploy local secret files.
4. **AI:** keep provider keys absent in the public offline demo. Any future activation requires rotated credentials, confirmed free eligibility/sponsor coverage, request quotas, and explicit live-test approval. Before exposing enabled AI publicly, add real authentication/abuse controls and durable rate/budget limits: current per-process counters reset on restart and do not provide a global spending limit. Gemini requires a confirmed free project; OpenRouter remains free-only; Swarms/Prune must not become automatic fallbacks. Prune gateway allowances do not pay upstream inference.
5. **Tiger Data:** optional connection helper is prepared, but rotation is unconfirmed, no live connection has been approved, and no schema or writes exist. Keep `DATABASE_URL` absent and rotation flag false for the deterministic demo. Table design remains proposal-only in Phase 12. Do not claim student progress is saved.
6. **Content/UI:** frontend owner must connect the existing interfaces if those features are required for submission. Research owners must verify occupation claims and remaining source links (including the previously unconfirmed Harvard reference). Clearly label unverified national figures and AI/deterministic status; do not advertise live AI, completed XP, or persistence as working.

Public interactive access also requires deciding how to replace or disclose the demo login and protect any sensitive inputs.
